# لوحة الأفكار

تحتاج إضافة **Dataview** (Settings ← Community plugins). كل جدول يتحدّث تلقائياً من صفحات الأفكار.

## عدد الأفكار لكل مشروع وحالة
```dataview
TABLE length(rows) AS "العدد"
FROM ""
WHERE type = "idea" AND !contains(file.folder, "_قوالب")
GROUP BY split(file.folder, "/")[0] + " · " + status AS "المشروع · الحالة"
SORT key ASC
```

## أفكار تحتاج مراجعة (تاريخ المراجعة قريب أو فات)
```dataview
TABLE split(file.folder, "/")[0] AS "المشروع", status AS "الحالة", review_by AS "مراجعة"
FROM ""
WHERE type = "idea" AND review_by AND date(review_by) <= date(today) + dur(14 days) AND status != "منفذة" AND status != "مرفوضة"
SORT review_by ASC
```

## الأفكار الجديدة وقيد الدراسة
```dataview
TABLE split(file.folder, "/")[0] AS "المشروع", status AS "الحالة", updated AS "آخر تحديث"
FROM ""
WHERE type = "idea" AND (status = "جديدة" OR status = "قيد الدراسة") AND !contains(file.folder, "_قوالب")
SORT split(file.folder, "/")[0] ASC, updated DESC
```

## المعتمدة وقيد البناء
```dataview
TABLE split(file.folder, "/")[0] AS "المشروع", status AS "الحالة", updated AS "آخر تحديث"
FROM ""
WHERE type = "idea" AND (status = "معتمدة" OR status = "قيد البناء")
SORT split(file.folder, "/")[0] ASC
```

## كل الأفكار
```dataview
TABLE split(file.folder, "/")[0] AS "المشروع", status AS "الحالة", review_by AS "مراجعة"
FROM ""
WHERE type = "idea" AND !contains(file.folder, "_قوالب")
SORT split(file.folder, "/")[0] ASC, status ASC
```
