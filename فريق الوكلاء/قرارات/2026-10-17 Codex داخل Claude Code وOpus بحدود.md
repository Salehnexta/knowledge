# Codex داخل Claude Code وOpus بحدود

**التاريخ:** 2026-10-17 · **صاحب القرار:** صالح

## القرار
Coder يعمل بـClaude Code، والكود يكتبه ويراجعه Codex، وJev يفحص كل تغيير. Opus 5.5 فقط لمراجعة الخطة والبنية قبل مرحلة، والمراجعة الأخيرة لكود الدفع والدخول وSSRF وبوابة الجودة، أو خطأ فشل فيه Codex مرتين.

## ليش
صالح: «استخدم اوبس ٥.٥ في اضيق واهم الحدود». «لا تستخدم كلود» تعني نماذج Claude في كتابة الكود، لا أداة Claude Code.

## تفاصيل من Hindsight
- الأوامر: ‎/codex:rescue للتنفيذ، و‎/codex:review أو ‎/codex:adversarial-review للمراجعة. التنسيق الروتيني بنموذج Haiku. كل استخدام لـOpus يُسجّل.
- بروتوكول المراجعة في مهام نفس اليوم: المؤلف والمراجع جلستان منفصلتان، وOpus للمراجعة الأخيرة لكود HMAC والدخول فقط، وكل مقترح دقيق يمر بمراجعة مستقلة وبوابة Jev قبل التطبيق (أقل من 0.8 يعني إيقافاً ينتظر القرار). صار Jev استشارياً لاحقاً: [[2026-10-23 Jev استشاري لا يمنع]].
- في صباح 2026-10-17 سُجّلت تعليمة «لا Claude Code ولا نماذج Claude، Codex فقط». الذاكرة نفسها تسجل أنها صُححت في نفس اليوم إلى القرار أعلاه.

## بدائل لم تُعتمد
نماذج Claude للكود الروتيني، أو ترك Claude Code كلياً (قراءة خاطئة صُححت).
