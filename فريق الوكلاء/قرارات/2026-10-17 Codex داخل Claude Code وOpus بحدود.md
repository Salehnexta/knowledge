# Codex داخل Claude Code وOpus بحدود

**التاريخ:** 2026-10-17 · **صاحب القرار:** صالح

## القرار
Coder يعمل بـClaude Code، والكود يكتبه ويراجعه Codex، وJev يفحص كل تغيير. Opus 5.5 فقط لمراجعة الخطة والبنية قبل مرحلة، والمراجعة الأخيرة لكود الدفع والدخول وSSRF وبوابة الجودة، أو خطأ فشل فيه Codex مرتين.

## ليش
صالح: «استخدم اوبس ٥.٥ في اضيق واهم الحدود». «لا تستخدم كلود» تعني نماذج Claude في كتابة الكود، لا أداة Claude Code.

## بدائل لم تُعتمد
نماذج Claude للكود الروتيني، أو ترك Claude Code كلياً (قراءة خاطئة صُححت).
