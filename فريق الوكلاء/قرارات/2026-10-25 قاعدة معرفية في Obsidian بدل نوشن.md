# قاعدة معرفية في Obsidian بدل نوشن

**التاريخ:** 2026-10-25 · **صاحب القرار:** صالح

## القرار
قاعدة المعرفة لكل مشاريع صالح خزنة Obsidian: ملفات Markdown في مستودع git (Salehnexta/knowledge)، مجلد لكل مشروع، وفي كل مشروع أفكاره وقراراته وأبحاثه. نوشن لا يُستخدم إلا للمشاركة مع غير التقنيين إن احتجنا.

## ليش
- صالح: «في البداية حق كل مشروع نبدأ بأفكار رائعة وبعدين تختفي في المحادثات، كيف نتجنب هذا».
- الوكلاء ومدير المشروع يكتبون الملفات ويقرؤونها مباشرة من الخادم، بلا واجهة برمجية وسيطة.
- سجل git يحفظ تاريخ كل تغيير ومن غيّره.
- الملكية: الملفات عند صالح وعلى خادمه، لا عند مزوّد خارجي.
- الربط بالكود: الصفحات تشير إلى مسارات الملفات والمستودعات، ومورفو يبقى متزامناً مع `docs/morvo/product-strategy.md`.

## بدائل لم تُعتمد
نوشن قاعدةً أساسية (يبقى خياراً للمشاركة فقط).
