# حماية Paperclip بالإيميل عبر Cloudflare Access

## الفكرة
حماية لوحة Paperclip بطبقة Cloudflare Access تطلب رمزاً بالإيميل قبل الدخول.

## ليش
طبقة أمان إضافية فوق تسجيل دخول Paperclip.

## الحالة الآن
أُنشئت ثم حُذفت في نفس اليوم. الحماية الآن تسجيل دخول Paperclip نفسه مع إقفال إنشاء الحسابات.

## سبب الرفض
إيميل حساب صالح في Cloudflare مختلف عن إيميله المعتاد، ثم قال: «ما أبي الإيميل».
