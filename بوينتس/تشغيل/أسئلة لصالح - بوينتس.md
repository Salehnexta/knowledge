# أسئلة لصالح - بوينتس

1. متى صار Keeper «بوينتس»، ولماذا؟
2. هل بوينتس نفس منصة سلسلة الإمداد، أم توجه جديد (سوق، عملاء، نموذج ربح)؟
3. ما المرحلة الآن: مكتمل ومغلق، أم إعادة إطلاق؟
4. الشركة المالكة: نكستا أم كيان آخر؟
5. العميل التجريبي (الحاجري): هل ما زال مستخدماً؟
6. الفريق الحالي ومن يملك الكود والاستضافة.
7. الملفات والروابط (الموقع، المستودع، العروض).
