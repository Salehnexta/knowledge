# خزنة المعرفة

هذه خزنة Obsidian لمشاريع فيونكس، ومجلد لكل مشروع. الهدف ألا تضيع أي فكرة أو قرار أو بحث في المحادثات الطويلة.

## المحتوى
- `Morvo/`: مشروع مورفو. ابدأ من `Morvo/00-خريطة مورفو.md`.
  - `أفكار/`: صفحة لكل فكرة، وفهرسها `00-فهرس الأفكار.md`.
  - `قرارات/`: صفحة لكل قرار مهم، وسجلها `00-سجل القرارات.md`.
  - `أبحاث/`: صفحة لكل بحث أو تجربة بأرقامها وتكلفتها ومسار ملفاتها.
  - `فئات/`، `تقنية/`، `تشغيل/`: ما نعرفه عن الفئات، والمحرك، والمهام المعلقة.
  - `_قوالب/`: قالب الفكرة وقالب القرار.

## الفتح في Obsidian
1. ثبّت Obsidian، ثم «Open folder as vault» واختر مجلد المستودع بعد استنساخه (`git clone`).
2. من الإعدادات ← Community plugins، ثبّت **Obsidian Git** وفعّله. اضبط «Auto pull on startup» و«Auto commit-and-sync» (مثلاً كل 10 دقائق)، فتصلك تحديثات الخادم وتُرفع تعديلاتك.
3. لاستخدام القوالب: الإعدادات ← Core plugins ← Templates، ومجلد القوالب `Morvo/_قوالب`.
4. الروابط بين الصفحات بصيغة `[[اسم الصفحة]]`، وكل صفحة تبدأ بخصائص (frontmatter) فيها النوع والحالة والتواريخ.

## نظام الحالات للأفكار
| الحالة | المعنى |
|---|---|
| جديدة | قيلت ولم تُناقش |
| قيد الدراسة | مقترحة وتنتظر قرار صالح |
| معتمدة | وافق صالح ولم يبدأ البناء |
| قيد البناء | العمل جارٍ |
| منفذة | مدموجة في الكود أو منشورة |
| مؤجلة | أُجّلت بقرار ولها تاريخ مراجعة `review_by` |
| مرفوضة | أُسقطت بقرار صريح وسبب الرفض مكتوب |

`review_by` إلزامي للمؤجلة وللمعتمدة التي لم تبدأ (حوالي 30 يوماً).

## القواعد
- **كل فكرة يُتفق عليها أو تُقترح تُكتب صفحتها في نفس الرد**، ويُحدَّث فهرس الأفكار. القرار يُكتب في `قرارات/`، والبحث في `أبحاث/`.
- كل رقم بمصدره وتاريخه ومسار ملفه. لا مفاتيح ولا أسرار في أي صفحة.
- لمورفو: `docs/morvo/product-strategy.md` في المستودع يبقى المرجع الرسمي، والخزنة متزامنة معه.

## المراجعة
- **أسبوعياً:** ملخص لصالح: الأفكار الجديدة، والمعتمدة الخاملة أكثر من 30 يوماً، والمؤجلة التي حلّ موعد مراجعتها، والمهام المعلقة عليه.
- **شهرياً:** مقارنة الواقع بصفحة `01-الرؤية الأولى.md` في جدولها الشهري.
